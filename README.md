# Lunix Print Agent — download

This repository only hosts the Windows installer for **Lunix Print Agent**, the small
program that lets Lunix print receipts and labels to this computer's printers without
the browser's print dialog. The source code is private.

**Download the latest version:**
[LunixPrintAgentSetup.exe](https://github.com/foxflue/lunix-print-agent-download/releases/latest/download/LunixPrintAgentSetup.exe)

- Windows only. On a Mac, Lunix keeps printing with the browser's print dialog.
- The installer is **not signed yet**, so Windows will show a warning.
  On "Windows protected your PC", choose *More info* → *Run anyway*.
  If **Smart App Control** blocks it, it cannot be bypassed on that PC.
- It does not need an administrator password and changes nothing in Windows.
